# Product content

FLOPX's authored content is its SAMPLE datasets, which live beside their loader at
`fastapi_backend/product/flopx/data/sample/*.json` (regenerated by
`product/flopx/data/sample_generator.py`), not here. This directory is the product
content scope the factory expects to exist; it holds no lesson, course or prose
content because the instance has none.

Every sample file carries a top-level `provenance` block (`kind: sample`,
`source: flopx-sample-v1`, authored date, basis note). Nothing under the sample
directory was observed anywhere; the frontend labels it SAMPLE wherever it appears.
